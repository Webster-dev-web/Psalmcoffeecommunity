# Psalmcoffeecommunity

Welcome to the Psalm Coffee Community website.
A modern coffee shop website created to showcase the Psalms Coffee brand, menu, atmosphere, and contact details.
This website was created to showcase the Psalm Coffee Community and provide a welcoming online space for visitors to learn more about the community.

## Features

- Responsive design for desktop and mobile
- Clean and welcoming layout
- Information about Psalm Coffee Community
- Easy-to-use navigation
